How it works

The calendar is built from a single data file where each holiday records its recurrence rule, a confidence rating, and the sources the date came from. Almost every entry is a recurring event — third Friday of September, last Thursday of October — so your calendar app does the date maths and the feed keeps working indefinitely.

Wine holidays are mostly self-declared, and the blog lists that catalogue them contradict each other constantly. Where sources disagree, the entry says so in its description rather than picking a date and pretending to be sure. The full data and sources are on GitHub if you want to check our work or add something we missed.
